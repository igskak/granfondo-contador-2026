# Gran Fondo Alberto Contador 2026 — маршрут

Интерактивная карта и профиль высот XV TotalEnergies Gran Fondo Alberto Contador
(Олива, Валенсия, 19 сентября 2026): по маршруту, обновлённому организаторами в сентябре 2026: 139,5 км, 2 510 м набора (старт через Oliva и Port del Sorell).

Открыть: https://igskak.github.io/granfondo-contador-2026/

- профиль высот с раскраской по уклону, замер любого участка мышью;
- подъёмы с длиной, средним и максимальным уклоном;
- рутометр с контрольным временем;
- калькулятор времени по мощности и весу.

Официальные данные (дистанция, набор, рутометр, лимиты) — с сайта организатора

и привязана к дорогам OpenStreetMap, высоты — SRTM (по треку 138,06 км / 2 409 м).
